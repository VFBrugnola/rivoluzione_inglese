# Rivoluzioni Inglesi — Dashboard Didattica

Dashboard interattiva per il liceo sulla storia delle rivoluzioni inglesi del XVII secolo: la Guerra Civile (1642–1651) e la Rivoluzione Gloriosa (1688–1689).

## Contenuti

- **Panoramica** — timeline comparata, protagonisti, concetti chiave
- **1642 · Guerra Civile** — cause, personaggi e fazioni (Roundhead, Cavaliers), fasi, approfondimenti su Puritani e Padri Pellegrini
- **1688 · Gloriosa** — cause, figure principali (Whig, Tory), fasi, Bill of Rights
- **Confronto** — tavola sinottica tra le due rivoluzioni

## Caratteristiche

- Interfaccia dark mode
- Immagini e ritratti embedded (nessuna dipendenza esterna)
- Completamente offline — file HTML singolo, nessun server richiesto
- Ottimizzata per la visualizzazione in classe

## Uso

Aprire `index.html` in un browser moderno, oppure visitare la versione online su GitHub Pages.
